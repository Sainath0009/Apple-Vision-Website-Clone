🌟 Apple Vision Pro Website Clone 🌟
🚀 Excited to Share My Latest Project! 🚀

I’m thrilled to announce the completion of my latest web development project: an Apple Vision Pro website clone! This project was a fantastic learning journey, and I’m incredibly proud of the outcome. By combining HTML, CSS, JavaScript, ScrollTrigger, and GSAP, I’ve created an interactive, visually engaging experience that mirrors the innovative design of the original Apple site.



🔑 Key Features
✨ Smooth Animations: Powered by GSAP, the site features fluid animations that significantly enhance the user experience, bringing the page to life.
🎢 Interactive Scrolling Effects: Thanks to ScrollTrigger, the website responds dynamically to scrolling, providing an immersive, engaging browsing experience.
📱 Responsive Design: The site is fully responsive, offering a seamless and beautiful interface across devices, from desktops to mobile phones.
